# 第四階段：額外功能實作 ✓ 已完成

## 1. 使用 H.NotifyIcon 提供 System Tray 支援

- [x] 支援將應用程式最小化至 System Tray。第十階段起這是可關閉的偏好（`AppSettings.CloseToTray`，預設開啟）；關閉時按下關閉鈕即結束程式。
- [x] 雙擊 Tray Icon 恢復視窗顯示。
- [x] Tray Icon 右鍵選單包含「最近開啟的程式」與「結束」選項，第十階段另加入「設定」（視窗隱藏時這是唯一入口）。
- [x] 從選單裡的最近清單啟動，走的是與主視窗同一條路徑（`MainWindow.LaunchRecent` 以 Id 找回項目後交給 `LaunchApp`），因此參數、工作目錄、以系統管理員身分執行都會帶上，也會記進最近清單。托盤原本自己 `Process.Start` 那筆記下來的路徑，等於把這三項全部丟掉——需要特定工作目錄或參數才能跑的程式，從托盤點會壞、從視窗點正常，同一個項目兩種行為。
- [x] `RecentLaunch` 因此只存項目 Id 與顯示名稱，不存路徑：路徑在啟動時從項目上讀，另存一份只會多一個會過期的副本（舊檔案裡的 `FilePath` 欄位讀取時直接忽略）。Id 一定找得回項目，靠的是 `RecentLaunchList.Purge` 在工作區變動時清掉已刪項目的記錄；真的落空就靜靜跳過，那代表選單開著的時候項目被刪了。

## 2. 資料夾分組管理 (Folder Grouping)

- [x] 支援建立、重新命名、刪除資料夾，將程式項目組織為群組。
- [x] 左側側邊欄以 ListView 呈現「未分類」與各資料夾，點選切換主內容區域。
- [x] 選取中的側邊欄項目顯示 accent 左側選取指示條，視覺一致。
- [x] 「未分類」固定置頂，無法移動；其他資料夾支援拖曳重新排序，順序持久化。
- [x] 可透過右鍵選單「移動至」子選單，在「未分類」與各資料夾之間移動項目。
